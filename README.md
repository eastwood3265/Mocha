# Mocha

一个专注于个人财务管理的 iOS App，支持债券、股票、黄金的当前持仓快照、资产存放处、独立预算，以及按目标攒钱的金桶。

再平衡功能以债券、股票、黄金、现金各 25% 为目标，支持限定投资项后的买入、卖出和按剩余工作日定投分配。

预算模块支持按分类定义月预算或年预算，并记录支出明细。月预算按每月 1 日进入新周期，年预算按 1 月 1 日进入新周期；历史账目不会被清空，当前周期已用金额会按支出日期动态聚合。

金桶模块通过存入和取出流水动态计算余额，支持可选目标金额、截止日期、归档和负余额提醒；数据不与预算、投资项或存放处联动。

设置模块支持切换全局主题色与投资收益的红绿显示习惯。金额输入支持千分位展示、清空和键盘完成操作，投资总盈亏可录入负数。

账单导入支持读取支付宝和微信支付导出的 CSV 个人对账账单，自动识别来源、预览交易，并按渠道交易号或稳定指纹去重。导入流水独立保存，不会在未经确认时直接计入预算；原始账单文件只在设备本地读取，不会上传。

基金平台接入采用“持仓快照”而非伪造交易流水。优先支持中国结算“基金 E 账户”导出的 XLSX：它可以一次覆盖腾讯理财通、蚂蚁财富、易方达等销售渠道，导入时按基金代码汇总同一基金的多渠道持仓。也可使用统一 CSV；系统优先按基金代码、其次按平台产品 ID、最后按标准化名称匹配，新快照更新已有投资项，较旧快照不会覆盖较新数据。CSV 标准列为：`快照日期、平台、账户、基金代码、基金名称、资产类别、持仓金额、总盈亏、收益口径、产品ID`，其中快照日期、平台、基金名称、资产类别、持仓金额必填。

### 基金持仓半自动同步

基金 E 账户目前仍需要用户完成登录和导出，Mocha 不保存账号密码，也不模拟登录。推荐在“设置 → 基金同步”开启每周日 20:00 提醒，并按以下方式配置 iPhone 快捷指令：

1. 新建个人自动化，选择“电子邮件”，以基金 E 账户导出邮件的发件人或主题作为过滤条件。
2. 从自动化输入中取得邮件附件；如果有多个附件，先筛选扩展名为 `.xlsx` 或 `.csv` 的文件。
3. 添加 Mocha 的“导入基金持仓文件”操作，把附件作为“持仓文件”传入。
4. 关闭“运行前询问”（系统版本允许时），保存自动化。

快捷指令会把文件交给 Mocha 并打开导入预览。用户确认预览后才写入持仓；解析失败或取消确认都不会修改现有投资数据。由于基金 E 账户的登录、验证码和导出动作没有稳定开放接口，这条链路的自动化边界是“邮件附件到达后自动送入 Mocha”，不能保证基金 E 账户端每日无人值守导出。

## 运行

直接打开已生成的工程：

```bash
cd Mocha
open Mocha.xcodeproj
```

选择模拟器后运行即可。数据通过 SwiftData 保存在设备本地。

`project.yml` 是工程的单一配置源。新增目录或 Target 后，可安装 XcodeGen 并运行
`xcodegen generate` 重新生成工程，避免长期手工维护易冲突的 `project.pbxproj`。

## 结构

- `App/`：应用入口
- `Core/`：跨模块可复用的格式化和 UI 基础设施
- `Features/Investment/Domain/`：投资快照、存放处模型与汇总规则
- `Features/Investment/Views/`：投资模块 UI
- `Features/InvestmentImport/`：统一基金持仓快照协议、匹配更新服务与导入 UI
- `Features/Budget/Domain/`：预算定义、支出账目和周期聚合规则
- `Features/Budget/Views/`：预算模块 UI
- `Features/GoldenBucket/Domain/`：金桶、存取流水和目标进度规则
- `Features/GoldenBucket/Views/`：金桶模块 UI
- `Features/Settings/Views/`：设置模块 UI
- `Features/StatementImport/`：支付宝、微信账单解析、去重、导入记录与 UI

每项投资直接记录持仓金额和总盈亏，不追踪成本与交易历史；现金底层盈亏固定为 0，用户侧只录入持仓金额。
